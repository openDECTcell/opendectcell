# Journals

How the project got here: bench sessions, experiments, dead ends and task lists, kept as they were written. They
are dated and often superseded by later findings; the documents one level up ([../README.md](../README.md)) are
the current state. Each page says at the top what it was for. You do not need them to use or change the code; they
are the place to look when you ask "why does it do that?" or "was that ever tried?".
